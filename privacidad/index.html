Aviso de privacidad

Borrador para el concurso. Un abogado debe revisarlo y completar los datos del responsable antes de recibir información de clientes reales.

Responsable. Pendiente de definir: nombre y domicilio del responsable.

Datos que se guardan. Correo de acceso, razón social, número de trabajadores, las marcas de cumplimiento que usted capture, las fechas de sus plazos y el resultado de las revisiones con IA.

Finalidad. Mostrarle su avance de cumplimiento y, si su cuenta está vinculada a un despacho, permitirle a ese despacho ver el resumen.

Archivos que sube. El archivo se envía a la API de Anthropic para generar la revisión y este sitio no lo guarda. Se conserva solo el resultado, que no debe reproducir datos de personas. Tache nombres, CURP, RFC, domicilios y salarios antes de subirlo.

Proveedores. Supabase para cuentas y base de datos, y Anthropic para la revisión con IA.

Derechos. Pendiente de definir: el medio para ejercer los derechos de acceso, rectificación, cancelación y oposición.
